# Credits and dependencies

## Authorship and template

Game project: Jaygovindhan Neelanarayanan.

The native engine is based on a pre-existing template carrying **Copyright (c) 2019 Pietro Lazzarotto** under the MIT license. Its `LICENSE.MD` is retained verbatim. Native dependency files retain their original source notices; these are not replaced by a blanket claim of sole authorship.

## Browser edition

- Three.js **0.180.0**, from the official npm package, is bundled locally in `Web/vendor/` with its MIT license.
- The marble, cubes, platforms, island, trees, portal, labels and other browser visuals are generated by the project's rendering code.
- Browser sounds are synthesized with Web Audio oscillators. No native music samples, font binaries, proprietary SDK files or imported model packs are required by the browser runtime.

## Native dependencies

The native project references GLFW, GLAD, GLM, stb_image, spdlog, Assimp, Bullet, FreeType and FMOD. Existing notices remain with their source. Missing FreeType 2.5.0 license/FTL notices and the GLAD 0.1.28 license were restored from their matching upstream releases. Assimp and Bullet notices are also collected under `docs/licenses/` from the retained source headers.

The public repository excludes FMOD SDK headers/import libraries and native binary libraries. Developers must obtain the SDK from FMOD. See [FMOD's SDK distribution terms](https://www.fmod.com/legal) and [licensing information](https://www.fmod.com/licensing). The native runtime has not been packaged as a public release.

## Native art and audio provenance

Original code comments attribute bounce audio to freesound.org, jump/pickup/heal/damage/pew audio to pixabay.com, the background track to nosoapradio.us, and the skybox to a vwall.it resource URL. These are provenance leads, not verified asset-specific license records. Model and texture creator/license details were not supplied as a complete manifest. Confirm the original sources and attribution requirements before redistributing a native binary or asset pack.

The native Arial font binary is kept local and ignored by Git. Use a font you are permitted to distribute when preparing a release. The browser edition uses system fonts and generated textures.
